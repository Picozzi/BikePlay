Technical Specifications

The Page For Engineers

Overview

BikePlay is made up of:

  • 2x Projection System Modules

  • 1x Controller Module

  • 1x Visor

  • 1x App

Work is divided into 3 teams: mechanical, electrical, software

Mechanical & Optics

Optical Specifications:

  • Lens Focal Length of 100mm

  • Virtual Image Distance of 254mm

  • Display brightness of 300 nits

Mechanical Specifications:

  • Weight of 280 grams

  • All weight is balanced across the helmet

  • Controller module (and projection) is adjustable to fit user’s preferences

Electrical

Electrical Specifications:

  • 2 hour battery length

  • Rechargeable, LiPo battery

  • Prevent SD card corruption on shutdown

Software

Software Specifications:

  • 1 Kb/s data transfer speed

  • Virtual images are displayed in a way not to obscure drivers FOV

  • BikePlay App is simple and easy to use

  • Computation is done on the phone to keep the helmet light
