Build Log - Week 3

February 3, 2023

Progress on BikePlay continued this week, with some more notable developments!

During last week’s testing, we determined that a smaller OLED could be used in the projection system. The new OLED is slated to arrive early next week, and to accommodate it, the projection system housing was shrunk down and reprinted. See below for a photo of the new components!

To help minimize the volume and weight of all components being attached to the helmet, testing was completed to decide on the best connector pins to the OLED. Initially, straight header pins were used, but these were long and took up a lot of space. Male-male connectors were tried next, with space reduction done by bending the pins, however this caused too much stress in the pins and several broke.

The final solution is to use header pins bent at 90° and plug them into female connectors. The pins have been ordered and are expected to arrive early next week.

Finally, for the developments in software! We are exploring the possibility of using a pre-existing software to run the navigation program instead of developing one in-house. While the in-house navigation program is near complete, a pre-existing one could improve user-friendliness of the app.
