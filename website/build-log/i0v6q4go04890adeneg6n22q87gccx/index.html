Build Log - Week 2

January 27, 2023

This week, with the arrival of all electrical components, the first iteration of BikePlay’s projection system was successfully assembled and tested!

For this, the mirror, OLED, and lens in the projection system were attached to their mounts in the projection system housing and it was mounted onto the helmet (see below).

The OLED was connected to the RPi and we were able to project the default images from the OLED onto the visor, while holding it in front of the helmet (see the video below).

Based on testing and calculations, we learned that we can use a smaller OLED, which will reduce the size of the projection system housing and therefore the weight of the helmet. We have since purchased a new, smaller OLED and are resizing the housing for the projection system.

In the software area of BikePlay, the search functionality of the app has been improved. A test user can now search for a topic and be presented with a list of options from which to choose. For example, they could search “coffee” and be presented with a list of nearby coffee shops to select.
