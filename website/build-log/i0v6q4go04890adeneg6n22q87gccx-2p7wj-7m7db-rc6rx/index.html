Build Log - Week 5

February 17, 2023

Lots of good progress on BikePlay happened this past week!

To start, the final version of the left-side projection system was printed - see some pictures below! These new parts solve all the mechanical problems that we’ve encountered and we don’t expect to need to print any new designs for them. Once they are tested, we can create mirrored parts of them to print for the right-side projection system.

The tint we ordered last week for the visor has also arrived and we are looking forward to testing it early next week.

We also tested the RPi pico last weekend. This modified RPi has a built-in charger for LiPo batteries, which reduces the number and complexity of components that need to be mounted on the helmet. It also has a built-in Bluetooth module and it was able to communicate with one of the OLEDs! See below for a quick testing video.

There are several small updates in BikePlay’s software. The appearance of the app is being tweaked to improve user friendliness, while several other functionalities - namely time and weather updates - are being added. See below for a demo of the communication between the app and RPi.
